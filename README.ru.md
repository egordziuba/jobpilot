# JobPilot Auto

Работает сам дважды в день: ищет вакансии Werkstudent, проверяет их, пишет адресное письмо из подтверждённых фактов и отправляет его по e-mail на подходящие вакансии, соблюдая лимиты. Потом сверяет ответы во «Входящих» и присылает тебе сводку.

## Установка (один раз, ~10 минут)

1. **Пароль приложения Gmail.** Открой https://myaccount.google.com/apppasswords (нужна включённая двухэтапная проверка), создай пароль для «JobPilot».
2. Двойной клик **setup.bat**: программа проверит Python, создаст `config.toml` и `profile/facts.toml` из примеров, прогонит тесты и откроет `.env`. Впиши пароль в строку `SMTP_PASSWORD=` и сохрани файл. Свои контакты впиши в `config.toml` → `[applicant]`, а в `profile/facts.toml` — только подтверждённые факты о себе.
3. Двойной клик **test-mail.bat**: тебе на почту придёт тестовое письмо.
4. Двойной клик **run.bat**: первый прогон в **пробном режиме**. Работодателям ничего не уходит, тебе приходит сводка со всеми готовыми письмами, плюс открывается отчёт.
5. Проверь 2–3 письма. Если всё устраивает, открой `config.toml` и поменяй `send_mode = "dry_run"` на `send_mode = "live"`.
6. Двойной клик **install-task.bat**: запуск каждый день в 08:15 и 15:15. Если ПК был выключен, пропущенный запуск выполнится при включении.

Перед переключением в `live` впиши в `data/already_applied.csv` все прошлые заявки (company, title, email, date). Этим компаниям инструмент писать не будет.

## Что уходит автоматически, а что нет

| Ситуация | Что делает |
|---|---|
| Близкая вакансия, подача по e-mail, без пробелов в требованиях | Отправляет сам (не больше 5 в день и 3 за запуск, одной компании не чаще раза в 30 дней) |
| Есть пробел (например, обязателен Power BI или немецкий C1) или вакансия смежная | Готовит письмо и ждёт тебя: `jp approve ID` |
| Подача только через портал / форму | Готовит текст и даёт ссылку; `jp fill ID` заполняет форму. Подаёшь сам (Enter), потом статус ставится сам или через `jp mark ID applied_manually` |
| В объявлении написано «Bewerbungen per E-Mail werden nicht berücksichtigt» | Считает подачу порталом, письмо не отправляет |
| Вакансия снята, истёк срок, дубль, уже подавался | Не отправляет |

Перед каждой отправкой инструмент заново проверяет, что объявление ещё висит. Статусы:
- «Попытка отправки» записывается до связи с сервером;
- «Отправка подтверждена сервером» ставится только после того, как Gmail принял письмо;
- «Результат неясен» означает, что связь оборвалась во время передачи. Повторно такое письмо не отправляется, пока ты не проверишь «Отправленные».

## Команды (`jp.bat` в этой папке)

```
jp status                 сводка по статусам
jp todo                   по очереди пройти вакансии, где нужен ты (то же, что todo.bat)
jp list prepared          что ждёт твоего решения
jp show ba:10001-...      вакансия, требования, письмо, история
jp approve ID             отправить подготовленное письмо при следующем запуске
jp skip ID                не подавать
jp mark ID interview      отметить интервью (rejected, offer, applied_manually, response)
```

```
jp fill ID                открыть форму работодателя в Edge и заполнить её (нужен install-forms.bat)
```

## Формы на сайтах работодателей

Один раз: двойной клик **install-forms.bat** (ставит Playwright, используется твой Edge).
Потом `todo.bat` или `jp fill ID`: программа открывает объявление, при необходимости жмёт «Jetzt bewerben», закрывает cookie-баннер с выбором «только необходимые», заполняет имя, контакты, адрес, «где нашёл вакансию», дату начала (`earliest_start = "ab sofort"`), загружает резюме, Anschreiben и Zeugnis и ставит только обязательную галочку согласия на обработку данных заявки (`accept_privacy`; Talentpool и рассылки — никогда).
По умолчанию зарплату, вопрос про разрешение на работу и свободные вопросы формы она оставляет тебе и подсвечивает оранжевым. Капчу не трогает. Отправляет только после твоего Enter; «форма отправлена» ставится, только если сайт показал подтверждение.

- Необязательный `[forms] available_until = ""`: дата окончания доступности в формате `DD.MM.YYYY`; пусто — оставить тебе (в поля даты передаётся `YYYY-MM-DD`).
- Необязательный `[forms] salary_hourly = 0`: ставка брутто в EUR за час; положительное число включает заполнение и выбор почасового периода, если он есть; годовую зарплату всегда заполняешь сам.

## Заявки, поданные вне программы

`data/marks.csv` (`id,status,date,company,title,channel,note`): статусы, проставленные вручную или Claude (`submitted`, `applied_manually`, `closed`). При каждом запуске программа переносит их в журнал, ставит дату подачи и не пишет этим вакансиям повторно. Уже продвинутые статусы (интервью, отказ) этот файл не откатывает.

Отчёт всегда лежит в `data/reports/latest.html`, журнал в `data/jobpilot.sqlite`, копии отправленных писем в `data/sent/`.

## Настройка

- **Факты о тебе:** `profile/facts.toml`. Письма собираются только из этих абзацев. Слова из `[forbidden]` (Power BI, VBA, Power Apps, «abgeschlossene Ausbildung» и т.п.) не попадут в письмо никогда.
- **Где искать:** `config.toml` → `[[search.ba]]` (Arbeitsagentur: Гамбург, твой город, удалённо) и `[[search.personio]]` / `greenhouse` / `recruitee` (карьерные страницы компаний).
- **Вакансия, найденная вручную** (LinkedIn, stellenwerk, сайт компании): строка в `data/manual_leads.csv` плюс текст объявления в `data/manual/<файл>.txt` (пример формата — в `examples/`). Дальше она проходит ту же проверку.
- **Резюме:** `documents/`, путь указан в `config.toml` → `cv_file`.

## Источники

- Jobsuche der Bundesagentur für Arbeit: тот же API, который использует сайт arbeitsagentur.de (поиск `/pc/v6/jobs`, детали `/pc/v4/jobdetails`).
- Фиды ATS: Personio (`/xml`), Greenhouse (`boards-api`), Recruitee (`/api/offers`).

HTML-страницы досок объявлений инструмент не парсит. CAPTCHA и входы в аккаунты не обходит.
